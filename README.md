### Rwanda Wetland and Forest Analysis
**Live app:** https://huggingface.co/spaces/Hykze1/Rwanda_wetland_and_forest

This is not just an analysis. It is an automated pipeline that:
- **Cleans the data automatically:** Rwanda's wetland and forest data is prepared without manual steps.
- **Generates the visualizations automatically:** the charts are built straight from the cleaned data.
- **Runs as an interactive web app** that anyone can open in a browser.

The project is built on extensive research into Rwanda's wetland and forest ecosystems, with InVEST used to model ecosystem services.

**Tools:** Excel, Python, InVEST (Natural Capital Project), Streamlit, Hugging Face
